Turn on auto low latency mode

Turn on ALLM in your TV settings, or set it to Automatic, so the console switches the TV to low-latency mode when a game starts. On PS5 set ALLM to Automatic. On Xbox enable Allow Auto Low Latency Mode. On most TVs ALLM and Game Mode only work on HDMI 1.
