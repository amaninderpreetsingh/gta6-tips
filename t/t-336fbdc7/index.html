Check the icon before leaving a location

Hover over an illegal operation's yellow map icon to see how many key valuables it holds, usually unique weapons, luxury watches and a safe with cash. A location only counts as fully completed when you collect all of them. Once you finish, the icon turns gray for a while, then the location respawns and you can do it again.
